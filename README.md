## 📌 Проекты

### 🗂 Apache-Log-Aggregator
Информационная система для автоматизированного сбора, обработки и анализа access-логов веб-сервера Apache. Парсит лог-файлы, обрабатывает и анализирует данные.

→ [Открыть репозиторий](https://github.com/Onimbus/Apache-Log-Aggregator)

### ♻️ bot_eco_fin
Telegram-бот, который по фото определяет тип мусора и подсказывает, в какой бак его выбросить. Помогает с раздельным сбором отходов.

→ [Открыть репозиторий](https://github.com/Onimbus/bot_eco_fin)

### 👁 Glazomer
Игра-тренажёр остроты зрения на Tkinter. Угадывай буквы, которые с каждым правильным ответом становятся всё меньше — мини-версия таблицы Сивцева.

→ [Открыть репозиторий](https://github.com/Onimbus/Glazomer)

### 🎯 HANGMAN
Классическая игра «Виселица» на Python. Угадай слово по буквам, пока не кончились попытки.

→ [Открыть репозиторий](https://github.com/Onimbus/HANGMAN)

### ✅ v1-ToDo
Простое ToDo-приложение на Python: добавляй задачи, отмечай выполненные и удаляй лишнее.

→ [Открыть репозиторий](https://github.com/Onimbus/v1-ToDo)

### 📚 viki_bot
Telegram-бот, который по слову находит статью в Википедии и присылает её прямо в чат.

→ [Открыть репозиторий](https://github.com/Onimbus/viki_bot)
